# 家谱成书输出制作模块 · 用户使用文档

> 适用版本：家谱成书模块 v1.0
> 适用对象：管理后台运营人员、家族管理员
> 最后更新：2026-09-20

---

## 一、功能说明

家谱成书模块用于将系统中已录入的家族成员数据，按传统家谱体例编排成书，并支持预览与导出。帮助家族把分散的电子成员信息整理为一份可打印、可收藏、可流传的成书文档。

**核心能力：**

| 能力 | 说明 |
|------|------|
| 创建家谱 | 为某个家族创建一份成书配置，填写书名、选择模板、编写序言/简介/家训等文案 |
| 编辑家谱 | 修改成书配置与各项文案内容 |
| 预览 | 在浏览器中查看成书排版效果（竖排/横排自动适配所选模板） |
| 导出 | 生成完整 HTML 文件下载到本地，可直接用浏览器打开或送印刷厂排版 |
| 启用/停用 | 控制某份家谱是否在可用列表中展示 |

**自动生成的成书章节：**

1. **封面** — 书名、副标题、家族名、模板名称、日期
2. **序言**（如填写）
3. **家族简介**（如填写）
4. **字辈表** — 从家族关联的字辈表自动生成（可在配置中关闭）
5. **家训**（如填写）
6. **世系说明** — 自动统计世代数、成员数，逐代列出传承脉络
7. **成员关系** — 每位成员的父亲、配偶、子女数量一览表
8. **世代成员明细** — 按世代逐代展示每位成员的生平信息
9. **附录**（如填写）

## 二、操作步骤

### 2.1 进入模块

1. 登录管理后台
2. 左侧菜单栏找到 **小程序管理 → 家谱成书**
3. 页面顶部显示家族选择下拉框，选中要操作的家族

> **注意**：若看不到「家谱成书」菜单，请联系超级管理员在「角色管理」中为您的角色勾选 `system:genealogy-book:list` 权限。

### 2.2 新增家谱

1. 点击右上角 **新增家谱** 按钮
2. 在弹窗中填写各项信息（详见下表）
3. 点击 **确认** 完成创建

### 2.3 编辑家谱

1. 在列表中找到目标家谱
2. 点击该行 **编辑** 按钮
3. 修改相应字段后点击 **确认**

### 2.4 预览家谱

1. 点击目标行 **预览** 按钮
2. 预览弹窗按所选模板展示排版效果：
   - **欧式 / 现代**：横排，从左至右阅读
   - **苏式 / 古典线装**：竖排，从右至左阅读
3. 检查排版效果后点击 **关闭**

> **提示**：预览为最终导出的近似效果。如需调整，先返回编辑修改对应文案或配置，再重新预览。

### 2.5 导出家谱

1. 点击目标行 **导出** 按钮
2. 浏览器自动下载 HTML 文件（文件名为「家族名-家谱名.html」）
3. 用浏览器打开文件查看完整效果
4. **打印**：浏览器中按 `Ctrl+P`，选择"另存为 PDF"或连接打印机输出

### 2.6 启停与删除

- **启用/停用**：点击列表中状态列的开关。停用后该家谱不再出现在可用列表，但数据保留，可随时重新启用。
- **删除**：点击 **删除** 按钮，在确认框中二次确认。**删除后数据不可恢复，请谨慎操作。**

## 三、表单字段说明

### 3.1 新增/编辑弹窗字段

| 字段 | 类型 | 必填 | 说明 |
|------|------|:---:|------|
| 家谱书名 | 文本 | ✅ | 最多 100 字。同一家族下书名不能重复 |
| 副标题 | 文本 | — | 最多 200 字，显示在封面书名下方 |
| 模板 | 单选 | ✅ | 四种体例，详见「四、模板说明」 |
| 正文字体 | 下拉 | ✅ | 宋体（衬线）/ 黑体（无衬线）/ 楷体 |
| 纸张大小 | 下拉 | ✅ | A4 / A3 / 16开（影响打印排版参考） |
| 封面样式 | 下拉 | ✅ | 默认 / 古典 / 简约 |
| 包含内容 | 开关×4 | — | 分别控制是否包含字辈表、成员简介、世系图、索引目录 |
| 序言 | 多行文本 | — | 家谱卷首序言，支持换行 |
| 家族简介 | 多行文本 | — | 家族源流、迁徙、发展概述 |
| 家训 | 多行文本 | — | 家族训诫、家规 |
| 字辈诗 | 多行文本 | — | 字辈排行诗（与系统自动生成的字辈表互补） |
| 附录 | 多行文本 | — | 其他补充说明，如修谱说明、赞助名单等 |
| 排序号 | 数字 | — | 数字越小越靠前，用于同家族多份家谱的排序 |

### 3.2 列表页字段

| 列 | 说明 |
|----|------|
| 书名 | 家谱书名 |
| 副标题 | 副标题内容，无则显示「-」 |
| 模板 | 所选体例，显示为彩色标签 |
| 包含内容 | 该家谱勾选包含的章节概览 |
| 排序 | 排序号 |
| 状态 | 启用/停用开关 |
| 创建时间 | 首次创建时间 |
| 操作 | 预览 / 编辑 / 导出 / 删除 |

## 四、模板说明

| 模板 | 排版方式 | 适用场景 |
|------|---------|---------|
| **欧式体例** | 横排从左至右，世代纵向排列，每代缩进一格 | 现代阅读习惯，便于快速查阅，适合配索引目录 |
| **苏式体例** | 竖排从右至左，世代横向排列 | 传统官修家谱体例，世代分明、长幼有序 |
| **现代体例** | 横排结合世系图与表格 | 信息密度高，支持富媒体内容，适合数字化存档 |
| **古典线装体例** | 竖排无标点，仿古线装书样式 | 适合收藏与祭祀场合 |

## 五、常见问题（FAQ）

**Q1：看不到「家谱成书」菜单怎么办？**
A：说明您的角色未分配该模块权限。请联系超级管理员，在「系统管理 → 角色管理」中为您的角色勾选 `system:genealogy-book:list` 权限，然后退出重新登录。

**Q2：新增家谱时提示"家族成员表不存在"怎么办？**
A：该家族尚未初始化成员数据。请先在「小程序管理 → 家族管理」中为该家族创建成员，或联系系统管理员初始化家族成员表，再返回创建家谱。

**Q3：导出按钮点击后没有反应？**
A：请检查浏览器是否拦截了下载弹窗。同时确认您的角色具有 `system:genealogy-book:export` 权限。

**Q4：预览效果与导出效果有差异？**
A：预览为快速近似渲染，导出为完整 HTML 文档，包含封面样式和打印分页控制。建议以导出后的实际效果为准。

**Q5：字辈表章节没有显示？**
A：请检查：① 编辑家谱时「包含字辈表」开关是否开启；② 该家族是否已关联字辈表（在「小程序管理 → 字辈管理」中设置）；③ 关联的字辈表状态是否为启用。

**Q6：成员信息在世系说明中不完整？**
A：成书数据完全来自家族成员表。请先在「小程序管理 → 家族管理 → 成员管理」中确保各成员的世代、父母、配偶、子女关系已正确录入。

**Q7：同一家族可以创建多份家谱吗？**
A：可以。但同一家族下书名不能重复。如需多个版本，请使用不同书名（如「张氏族谱·2026修订版」）。

**Q8：如何批量打印？**
A：导出 HTML 文件后，用浏览器打开，按 `Ctrl+P` 选择"另存为 PDF"。PDF 文件可直接送印刷厂，支持批量打印。

## 六、权限说明

| 权限标识 | 控制功能 |
|---------|---------|
| `system:genealogy-book:list` | 查看家谱列表 |
| `system:genealogy-book:create` | 新增家谱（显示"新增家谱"按钮） |
| `system:genealogy-book:update` | 编辑家谱 / 切换启停状态 |
| `system:genealogy-book:delete` | 删除家谱 |
| `system:genealogy-book:export` | 导出 HTML 文件 |
